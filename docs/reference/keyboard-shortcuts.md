# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save file |
| `Ctrl+B` | Bold (edit mode) |
| `Ctrl+I` | Italic (edit mode) |
| `Ctrl+K` | Link (edit mode) |
| `Ctrl+Z` | Undo (edit mode) |
| `Ctrl+Tab` | Cycle tabs |
| `Ctrl`+wheel | Zoom (view mode) |

Formatting shortcuts and the toolbar actions each apply as a **single undo step**, so
`Ctrl+Z` reverts one formatting action at a time.
